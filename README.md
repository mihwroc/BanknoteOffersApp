# BanknoteOffersApp

## Purpose

BanknoteOffersApp is a personal project for collecting and archiving publicly available banknote offers from Allegro.

The application uses the official Allegro REST API to retrieve offer information for personal research and collection management.

## Features

- Retrieve publicly available banknote offers.

- Collect offer information for archival purposes.

- Store retrieved data locally for later analysis.

## API

The application uses the official Allegro REST API.

API documentation: https://developer.allegro.pl/

## Usage

This application is intended for personal use only. It is not a commercial service and is not intended for use by other sellers.
